# connector/creality — Creality (позже)

Парк оператора с Creality (K2 Max и др.) сейчас **недоступен** — коннектор пишется,
когда оператор откроет парк. До железа допустимы только работы против доков/эмуляторов.

Ожидания (проверить на железе, НЕ факт): K-серия на Creality OS (форк Klipper);
у части моделей Moonraker доступен или включается — тогда коннектор здесь только
добывает соединение/авторизацию, а протоколом работает готовый
`driver/moonraker/MoonrakerDriver`.

Реализует `../common/connector.ts`; auth с участием оператора — через
`OperatorConfirmGate` (см. `../common/README.md`).
