# Локатор — фирменный графический элемент Sber AI

← [readme.md](readme.md) · Источник: гайд Sber AI, с. «Локатор. Элементы / Динамика и размеры / Размещение / Примеры».

Локатор — **второй графический элемент бренд-системы** (после логотипа). Инструмент цифрового
мира, символизирующий процесс поиска нового, расширяющий возможности человека. Окрашивается
фирменным градиентом.

## Анатомия (сверху вниз по слоям)

| Элемент | Роль |
|---|---|
| **Стрелка** | Верхний акцент. Размер строго фиксирован. Жёлто-зелёный кончик (край градиента). |
| **Сектор** | Основное тело. Угол меняется от объёма текста на секторе, **кратно шагу сетки 5°**. Состоит из **двух слоёв** (контроль прозрачности на разных фонах + яркость градиента). Исключение — непрозрачный сектор: один слой. |
| **Шлейф** | Под сектором, создаёт ощущение динамики. Угол конца шлейфа **больше угла конца сектора на 10–15°**. |
| **Круг** | Самый нижний, всегда статичный слой. |

Границы шлейфа и круга должны однозначно считываться со стороны сектора.

## Динамика и размеры

- Локатор движется **строго по часовой стрелке**.
- Стрелка Локатора **всегда в верхней части окружности** (верхняя «голубая зона»).
- **Минимальный угол сектора — 135°**, **максимальный — 270°**.
  - < 135° — брак (пропорции цветов не сохраняются/не узнаются).
  - > 270° — брак.
- 🚫 **Запрещена анимация вращения Локатора при взаимодействии с человеком.**

## Размещение в макете

- Макет делится на **4 равные части** по горизонтали и вертикали.
- Область для сектора занимает **3/4 площади** макета. В её пределах Локатор можно
  **поворачивать, отражать зеркально и кадрировать**.
- Размер сектора зависит от объёма текста в нём и композиции фото. Для вертикальных и
  горизонтальных форматов — единые принципы.
- Шлейф и круг должны быть **полностью видны** хотя бы с одной стороны макета. Стрелка может
  выходить за край, но её градиент должен полностью считываться.

## Применение в портале

Локатор — сильный кандидат на **фирменный декоративный/загрузочный элемент** портала
(вместо/вместе с абстрактными blur-пятнами `aurorabg`). Естественно ложится на «поиск по
форме модели» (север V1) и на процесс генерации/слайсинга. Реализация — SVG с градиентом
палитры; уважать `prefers-reduced-motion` (и без того запрещено вращение при интеракции).
Связь: [../design/palette.typography.md](../design/palette.typography.md) (фон/освещение),
[../design/motion.md](../design/motion.md) (анимация).
