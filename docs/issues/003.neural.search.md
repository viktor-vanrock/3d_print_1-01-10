## Суть

Семантический поиск на русском по title/description/tags. GigaEmbeddings (Сбер) — MIT-лицензия, можно self-host, не только платное API, ruMTEB 69.1. Альтернатива — Qwen3-Embedding (Apache 2.0, до 70.58). Хранилище — pgvector (не отдельная vector DB, Postgres уже есть). Гибрид с full-text search, не чисто векторный поиск.

## Фазы

- [ ] Фаза 1 — `/embed` в `apps/giga` (GigaChat API) + колонка pgvector + простой векторный поиск
- [ ] Фаза 2 — гибридизация с full-text search + фильтрами по фактам (материал/принтер/категория)
- [ ] Фаза 3 — self-hosted эмбеддинги при росте объёма/стоимости API

## Открытые вопросы

- Тарифы GigaChat Embeddings API при заметном объёме — уточнить у Сбера (та же регистрация организации, что для 002).
- Порог, при котором переходим на self-hosted (деньги или нагрузка) — не блокирует старт, фиксируем как будущий триггер.

Полный разбор с источниками — в спеке.
