## Фон и освещение

- Основа — **почти чёрный тёплый тил**, не чистый чёрный и не графит: `#080808`…`#001010`…`#082020` (кластер тёмных тонов по кадрам). У нас — `--bg: #0a1512`.
- Поверх — **статичный луч-прожектор**: широкий мягкий радиальный градиент от угла (обычно верх-право), не движется — задаёт «студийный свет». Отдельный солидный слой, не декоративные пятна.
- **Цвет прожектора адаптируется под сцену**: обычно зеленовато-мятный, но на синих объектах (ваза, «Крючок настенный») — синий/голубой. Паттерн «амбиентный свет под доминирующий цвет 3D-объекта» (как Apple TV screensaver / Spotify Canvas). На будущее — для каталога/карточек моделей, где есть 3D-объект.
- **Лёгкое зерно** поверх всего — едва заметная «плёночная» пыль (SVG `feTurbulence`, opacity ~0.05, `mix-blend-mode: overlay`), не мультяшный шум.
- 2–3 мягких blur-пятна декоративного акцента, медленно дрейфующих — наша добавка для экранов без 3D-объекта (логин).

**Реализация** — `apps/web/src/pages/aurorabg.{tsx,css}`: `.aurorabgSpotlight` + `.aurorabgGrain` + 3 `.aurorabgBlob`.

## Палитра и семантика

| Роль | Hex (прибл.) | Где видно |
|---|---|---|
| Фон (тёмные кластеры) | `#080808`–`#001818`–`#082020` | вся сцена |
| **Акцент/успех (мятно-зелёный)** | `#34d399`…`#6ee7a7`…`#9eeec3` (градиент) | заголовки-акценты, primary-CTA, hero-панель прогресса, «принтер готов» |
| **Внимание/очередь (янтарь)** | `#fbc281` (текст), бледно-золотой badge | очередь, ожидание, «есть очередь», **warn-алерт** |
| **Деструктив/критично (коралл)** | тёплый приглушённый красно-розовый (не ядовитый) | «Отменить печать», удаление, **critical-алерт** |
| Текст основной | почти белый `#eef5f2` | заголовки, тело |
| Текст вторичный | приглушённый серо-зелёный | подписи, мета, eyebrow |

Токены — `apps/web/src/theme/tokens.css` (`--accent`, `--accent-warn`, `--accent-danger`, `--bg`, `--surface`, `--border`, `--text`, `--text-dim`).

**Два режима зелёного:**
1. **Тонкий/текстовый** — цвет акцентного слова заголовка или иконки-точки статуса на тёмном фоне.
2. **Hero-панель (разворот контраста)** — для ОДНОЙ ключевой метрики на экране (проценты прогресса печати) вся карточка заливается ярким мятным градиентом (`#68e2a2`→`#9eeec3`), а число внутри — **тёмное, почти чёрное**, не белое. Приём редкий — только для главной метрики (видно на кадре прогресса печати «3%»), не для кнопок вообще.

**Янтарь и коралл — семантические, не декоративные:** янтарь = «требует внимания, не ошибка» (очередь, ожидание, warn); коралл = «необратимое/деструктивное» (отмена, удаление) и critical-алерт. На кадре печати кнопка «Отменить печать» несёт **коралловый круглый ×** — деструктив всегда коралловый, никогда зелёный. Как это используется в алертах печати — [status.alerts.md](status.alerts.md).

## Типографика

- **Display/заголовки** — геометричный, округлый гротеск (круглые чашки у «р/е/д/о»); крупные цифры на большом кегле. Реализация — self-hosted **SB Sans Display** (см. [brand/typography.md](../brand/typography.md)), токен `--font-display`.
- **UI/тело** — нейтральный читаемый гротеск, self-hosted **SB Sans Text**, `--font-sans`.
- **Eyebrow/мелкие подписи** — uppercase + межбуквенный трекинг + точки-разделители («СЛУЧАЙНАЯ МОДЕЛЬ · ГОТОВО К ПЕЧАТИ»), приглушённый серый.
- **Двухцветные заголовки** — обычная строка одним цветом + одно акцентное слово/строка мятным. На кадре AI-экрана: «Какую» (зелёным) «3D-модель генерируем?» (белым) — акцентное слово выделено цветом, крупный кегль.

**Начертание — 2026-07-18, решение оператора (обновляет более раннее «light/regular» из
референса inspiration.mp4):** «слишком много тонких букв, надо больше жирности, но
уместно». База текста поднята с браузерного default 400 до **500** (`body` в
`tokens.css` — наследуется везде, где компонент не задаёт свой вес явно, не трогает то,
что уже осознанно взвешено отдельным правилом). Точечно усилены самые заметные тонкие
места: `.uiHeading` (главный двухтоновый заголовок) и `.uiStatTileValue` (крупные цифры-
метрики) — **300 → 700**; `.homeGhostInput` (хиро-инпут «Что напечатаем?») — **300 → 600**
(поле ввода, не статичный заголовок — чуть легче, чтобы набранный текст не читался как
плакат); часы в шапке и на морде принтера (`.faceClock`) — **300 → 700**. Все веса — реальные
файлы начертания SB Sans (300/400/500/600/700 самостоятельные `.woff2`, не браузерный
синтетический bold).

Точные размеры кегля по ролям (px @1440) — [metrics.md](metrics.md).
