# Политика доступа — ЗАКРЫТАЯ РАЗРАБОТКА (a priori, не нарушать)

**Директива оператора 2026-07-11.** Пока идёт закрытая разработка, ОБА контура — `dev.3mf.tech` и
`3mf.tech` (прод) — закрыты за auth-гейтом. Публичный/анонимный доступ к любой странице или API =
**КРИТБАГ**, не фича.

## Правило (железно)
- **Гость (без сессии) видит ТОЛЬКО `LoginPage`** на ЛЮБОМ роуте. Никаких «публичных роутов»
  (`/`, `/project`, `/feed` и пр.) для гостя — карвач MF-850/MF-912 отключён на время закрытой разработки.
- **api закрыт preHandler-гейтом**: без cookie-сессии открыты ТОЛЬКО `/health` и `/auth/*`.
  `OPEN_PATH_PREFIXES` — пусто (кроме перечисленного). Не добавлять публичных префиксов.
- **Управляется одним флагом** (напр. `CLOSED_DEV=1` / `PORTAL_PUBLIC=false`), стоит на ОБОИХ env
  (dev + прод). Открыть публично — ТОЛЬКО явным решением оператора (снять флаг), не втихую в карте.
- `dev_bypass` — только dev (`NODE_ENV!=production`), НИКОГДА на проде.
- **Webcheck агентов не ломается**: заходит с cookie `portal_session` (служебная сессия) → проходит гейт.
- Зеркальность dev↔prod: гейт идентичен на обоих (см. `docs/infra/domain.map.md`).

## Кто следит
Любая карта/PR, открывающая роут или API гостю в закрытой фазе — Reviewer/QA заворачивают, Back/Front
чинят немедленно. При снятии закрытой фазы оператор явно объявляет и снимает флаг.
