# 001 · 3MF как единственный формат хранения и выдачи

## Суть

Пользователь загружает модель в любом формате, сервер конвертирует и оптимизирует, храним и отдаём только 3MF (теперь ISO/IEC 25422:2025). Задача — выбрать правильный профиль расширений (Materials/Production обязательны, Secure Content и экспериментальный Volumetric v1.0 — дифференциаторы), не просто «взять всё». Конвертация — `trimesh` (геометрия) + `lib3mf` (упаковка с расширениями).

## Фазы

- [ ] Фаза 1 — MVP-конвейер (STL/OBJ → 3MF, Core+Materials+Production)
- [ ] Фаза 2 — Secure Content (защита авторов)
- [ ] Фаза 3 — приём STEP
- [ ] Фаза 4 — Volumetric как флагманская фича
