# CODE OF CONDUCT

Адаптация [Contributor Covenant](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/) под закрытую команду portal.ru.

## Наши стандарты

Ожидаемое поведение:
- Уважительная, конкретная обратная связь по коду и решениям — критикуем подход, не человека.
- Открытость к разным уровням опыта; объяснять, а не отмахиваться.
- Признавать ошибки, если попросили поправить — поправить, а не спорить из принципа.
- Не молчать о блокерах — писать в PR/issue сразу, не под конец спринта.

Недопустимое поведение:
- Оскорбления, переход на личности, токсичный тон в код-ревью и обсуждениях.
- Дискриминация по любому признаку.
- Публикация чужих приватных данных (в т.ч. секретов/ключей из `SECURITY.md`) без согласия.
- Саботаж чужой работы (намеренный force-push поверх, слом CI без причины и т.п.).

## Область действия

Действует во всех пространствах проекта: PR/issues/код-ревью на gitverse.ru, Wiki, внутренние чаты по проекту.

## Разрешение конфликтов

1. Прямой разговор между участниками — большинство трений решаются на этом шаге.
2. Если не помогло — эскалация [@plag](https://gitverse.ru/plag).
3. Систематическое нарушение — вплоть до отзыва доступа к репозиторию.
