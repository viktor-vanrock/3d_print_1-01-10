# Измеренные метрики (инструментально по кадрам inspiration.mp4)

← [docs/design/readme.md](readme.md)

Замерено PIL/numpy по нативным кадрам (1972×1488) и **нормализовано к референс-канве 1440px** (значения самосогласованы: 2 карточки 631 + зазор 18 + поля 80×2 = 1440). На узких экранах масштабировать через `clamp()`; радиусы — почти абсолютные.

**Скругления (радиусы):**
- Крупные карточки-действия / панели-стекло — **≈28px** (ratio радиус/высота ≈ 0.12).
- Пилюли, чипы, статус-бейджи, аватары — **999 (полное)**.
- Тайлы выбора (S/M/L) — squircle, **≈20–24px**.
- Поля ввода — **≈22–28px**.

**Кнопки и карточки-действия (нижний ряд):**
- Каждая **≈631×237px**, аспект **2.67:1**, радиус 28.
- **Зазор между карточками ≈18px**, боковые поля экрана **≈80px** (≈5.6% ширины).
- Внутри: заголовок + подпись слева, **круглая иконка-аффорданс справа ≈64px** (primary — зелёная заливка, secondary — нейтральная ←). Кликается вся карточка.
- Один primary (зелёный) на экран; вторичная — нейтральное стекло.

**Типографика (cap-height @1440, для CSS — примерно эти px):**
| Роль | Размер | Начертание |
|---|---|---|
| Hero-заголовок (двухтоновый) | **~54–58px** | Unbounded light/regular |
| Огромная метрика (проценты, «3%») | **~100px+** | Unbounded light, тёмная на зелёном |
| Заголовок в топбаре / название | **~24px** | Unbounded/medium |
| Тело / подзаголовок | **~16–18px** | Inter/Golos |
| Eyebrow (UPPERCASE + трекинг) | **~10–11px** | Inter, приглушённый |

**Контролы:**
- Статус-пилюля печати — высота **≈38px** (radius 999).
- Чип-подсказка — высота **≈50–58px** (radius 999, тач-дружелюбно).
- Часы в топбаре — **≈24px**.

**Цвета (сэмплировано):**
- Акцент видео — **`#64e49d`** (мятный; попадает в наш градиент `#34d399…#9eeec3`, но чуть светлее токена — при желании сдвинуть `--accent` к `#4ad...`).
- Поверхность-стекло — **`#1c3441`…`#293636`** (тёмный десатурированный тил).
- Фон — почти чёрный тёплый **`#08…0a`**, теплеет к тилу под прожектором.
- Текст основной — near-white `#eef5f2`.

**Композиция:** контент по центру, симметричные поля ≈80px; вертикальный ритм eyebrow → заголовок → контент → ряд действий внизу; широкий двухколоночный ряд действий (631+18+631). Иерархия яркости = иерархия важности.

> Метод: `ffprobe`/`ffmpeg` (нативные кадры) + PIL/numpy (границы по медиане яркости столбцов/строк — устойчиво к тексту; радиус — по дуге угла; кегли — по вертикальному размаху ярких строк глифов; цвета — точечные сэмплы). Кадры — `scratchpad/nat`, `scratchpad/frames` (не в git).
