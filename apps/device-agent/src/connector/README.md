# connector/ — вендорные коннекторы к принтерам (серверная сторона)

> Создано 2026-07-16 по директиве оператора. Владелец — «Девайсы: коннектор» (лид Fleet).

**Коннектор** — серверный код, которым воркер с LAN-доступом подключается к принтеру
**через сеть/веб** (HTTP/WS/vendor-API). Это НЕ вмешательство в принтер и НЕ прошивка
(прошивочная история живёт в `printer.firmware.template` и эпике UltraPrint).

## Разделение ответственности: connector vs driver

- `../driver/` (**протокол**) — как говорить с конкретной прошивкой, когда соединение
  уже есть: `PrinterDriver` (status/pause/resume/cancel/upload/startPrint/camera).
  Пример: `driver/moonraker/`.
- `connector/` (**подключение, вендор**) — как до этого соединения добраться у
  конкретного вендора: discovery в LAN, auth-хендшейк (токены, подтверждение на
  экране принтера, подтверждение оператора), lifecycle/reconnect. Результат работы
  коннектора — готовый к использованию `PrinterDriver`.

Один вендор может отдавать чужой driver (FLSun — форк Klipper → `MoonrakerDriver`),
а может требовать собственный (Snapmaker U1).

## Структура

```
connector/
  common/     — общий контракт PrinterConnector + подтверждение оператора (без него не строится ни один вендор)
  snapmaker/  — Snapmaker U1: целевой принтер №1 (форк Orca, LAN, token/confirm)
  creality/   — Creality (K-серия): позже, парк недоступен
  flsun/      — FLSun (T1 Max и др., Klipper/Moonraker): позже, парк недоступен
```

## Правила

1. Каждый вендор — своя папка, свой README с фактами о протоколе (источник + дата).
2. Все коннекторы реализуют `common/connector.ts` (`PrinterConnector`).
3. **Auth с участием оператора обязателен**: если принтер требует токен/подтверждение,
   коннектор обязан пройти через `OperatorConfirmGate` (уведомление в Telegram через
   бота, ожидание ответа) — никаких тихих попыток подключения к железу.
4. Живые прогоны — только через полигон (`printer-polygon` на Mac оператора) или
   будущий парк-воркер. Из dev-vm до LAN-принтеров доступа нет.

## Текущее состояние железа (2026-07-16)

Доступен ровно один принтер: **Snapmaker U1, 192.168.88.82 (LAN-режим)**. Остальной
парк оператор откроет позже — коннекторы creality/flsun пишутся против доков и
эмуляторов до появления железа.
