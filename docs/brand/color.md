# Цвет — коммуникационная палитра и градиент Sber AI

← [readme.md](readme.md) · Источник: официальный гайд Sber AI ([assets/SberAI_guide.pdf](assets/SberAI_guide.pdf), с. «Коммуникационная палитра», «Фирменный градиент»).

## Коммуникационная палитра (4 основных цвета суббренда)

Основные цвета суббренда. Используются во внешних коммуникациях, печатных материалах,
интерьере и прочих физических объектах. **Именно основная палитра строит фирменный
градиент и локатор суббренда.**

| Цвет | HEX | RGB | CMYK | Pantone |
|---|---|---|---|---|
| **Королевский** | `#515DAD` | 81 / 93 / 173 | 78 / 70 / 0 / 0 | 2116 C |
| **Голубой** | `#5AB0FF` | 90 / 176 / 255 | 55 / 21 / 0 / 0 | 284 C |
| **Аметист** | `#8253AA` | 130 / 83 / 170 | 57 / 79 / 0 / 0 | 2587 C |
| **Аквамариновый** | `#6BEAC7` | 107 / 234 / 199 | 48 / 0 / 33 / 0 | 3533 C |

**Дескриптор.** Основной цвет суббренда (цвет дескриптора) должен преобладать при построении
градиента. Для Sber AI акцент «AI» в логотипе — Королевский `#515DAD`.

## Зелёный «Сбер» (мастер-бренд)

Зелёный — цвет **мастер-бренда Сбер**, не суббренда. В гайде он используется только для
заголовков секций (акцентная зелёная строка). Полноцветный логотип суббренда **запрещено**
размещать на цвете «Зелёный Сбер». В коммуникациях суббренда зелёный самостоятельно как
акцент не тянем — он принадлежит мастер-бренду.

## Фирменный градиент

Строится из цветов палитры по оси **Аметист/Королевский → Голубой → белый → Аквамариновый**
(фиолетово-синий слева, аквамарин справа, светлое ядро). Используется во всех коммуникациях
суббренда: самостоятельно и на фирменном локаторе. В цвета градиента окрашивается иконка
мобильного приложения.

```
Светлый градиент (canonical):
  linear-gradient(105deg,
    #8253AA 0%,     /* аметист */
    #515DAD 22%,    /* королевский */
    #5AB0FF 55%,    /* голубой */
    #eaf7f4 78%,    /* светлое ядро */
    #6BEAC7 100%);  /* аквамарин */
```

### Градиент на тёмном фоне (тёмная тема)

Для тёмной темы — особый стиль: **яркие пятна основных цветов на чёрном фоне** (не
линейный градиент, а мягкие радиальные пятна аметиста/королевского/голубого/аквамарина,
всплывающие из чёрного).

```
Тёмный градиент (пятна на #000):
  radial-gradient пятна #515DAD / #8253AA / #5AB0FF / #6BEAC7
  малой насыщенности, разнесённые по чёрному полю, с мягким falloff.
```

## Как это ложится на палитру портала

Портал (`docs/design/palette.typography.md`) сейчас держит тёмную тил/изумрудную сцену с
мятно-зелёным акцентом `#34d399…#6ee7a7`. Аквамарин Sber AI `#6BEAC7` — фактически тот же
угол оттенка, что и наш мятный, поэтому **тёмная база совместима**. Расхождение — в акценте:
у портала зелёный самостоятельный, у Sber AI зелёный принадлежит мастер-бренду, а акцент
суббренда — фиолетово-синий градиент.

✅ **Решение оператора (2026-07-16): акцент портала остаётся мятно-зелёным.** Токены
`--accent*` не меняем. Фирменный фиолетово-синий→аквамарин градиент Sber AI используем как
**справочник для брендовых поверхностей** (логин, обложки, локатор, hero, паттерн, OG-карточки),
а не как функциональный акцент (CTA/статусы). Тёмная сцена портала совместима: аквамарин
`#6BEAC7` ≈ наш мятный. См. [readme.md § «Реконсиляция»](readme.md).
