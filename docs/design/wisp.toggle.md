# Висп-тумблер темы

← [docs/design/readme.md](readme.md) · часть капсулы — [header.capsule.md](header.capsule.md)

Переключатель темы — не банальный свитч, а **висп**: шарик-«заряд энергии» на треке солнце↔луна. Красится токенами темы (`--accent/--accent2`) — сам адаптируется под режим.

Управление сенсор-first:
- **тап по треку** = переключить;
- **плавно тянуть** (pointer capture, ходит за пальцем; отпустил — защёлкивается к ближайшей стороне; тап отличаем от drag по сдвигу <5px).

Пассивная жизнь «живой, но деликатный»: дыхание свечения ~3с + редкая искра-кольцо раз в ~5с; при перетаскивании разгорается и чуть вытягивается по ходу. Полюс, на котором стоит висп, гаснет («съеден» свечением). Всё off при `prefers-reduced-motion`.

Реализация: `theme/themetoggle.tsx` + `theme/wisp.css`.
