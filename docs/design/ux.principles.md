# Сквозные UX-принципы (требования, не код — из демо-мастерской)

## Доверие и evidence в интерфейсе (MF-1391)

UI не обещает capability по наличию кнопки: источником истины является ответ API. Owner/operator
получают `202 queued`, viewer/guest — `403 role_forbidden`, read-only key — `403 missing_scope`,
rate limit — `429 RATE_LIMITED`. Отказ доступен с клавиатуры и скринридером, описан текстом и
состоянием, а не только цветом; тач-цель не менее 48px. Секреты, cookie и Bearer не попадают в
UI-evidence или логи.

Основание: [product/trust.md § Evidence-поток trust journey v1](../product/trust.md).

- Тёмная OLED+glass эстетика (сверить с общей темой `design.md`).
- Кастомные SVG-иконки, не эмодзи.
- Акцент по срочности выражается яркостью + пульсацией элемента, не
  только цветом/текстом.
- Контент по центру экрана + хром-overlay (панели управления по краям,
  не перекрывают контент).
- Переходы между состояниями — через `setTimeout`, НЕ `requestAnimationFrame`:
  rAF ставится на паузу когда вкладка в фоне, анимация зависает
  на `opacity:0` — проверенная грабля демо, закладывать сразу.
- Скелетоны при загрузке + count-up анимация чисел вместо мгновенной
  подстановки значений.
- Всё анимационное — под `prefers-reduced-motion`.
- Тач-цели ≥48px (сверить с `design.md` — не дублировать, а подтвердить
  соответствие).
