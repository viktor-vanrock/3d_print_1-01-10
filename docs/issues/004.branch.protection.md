# 004 · Защита ветки `main`

**Статус:** open
**Тип:** infra
**Создано:** 2026-07-03

## Суть

`main` сейчас не защищена (`protected: false`, проверено через API). Публичный API GitVerse не поддерживает branch protection вообще (см. `docs/infra/readme.md` § «GitVerse Public API») — только веб-UI.

## Что сделать

`gitverse.ru/plag/portal.ru` → Settings → Branches → Branch protection rules → Add rule → ветка `main`:
- обязательные ревью ≥1
- запретить прямой push
