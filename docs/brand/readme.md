# BRAND — официальный бренд-гайд Sber AI

Декомпозиция **официального брендбука Sber AI** ([assets/SberAI_guide.pdf](assets/SberAI_guide.pdf),
53 стр.) в структурные `.md`. Это **авторитетный источник** фирменного стиля экосистемы Сбер:
портал (`3mf.tech` / `portal.ru`) — продукт Sber-экосистемы (авторизация SberID, гейт
`@sberbank.ru` / `@sberdevices.ru`), поэтому его визуальный язык должен опираться на этот гайд.

> **Соотношение с `docs/design/`.** `docs/design/` — прикладная дизайн-система портала («как
> выглядит и устроен наш UI», канон-референс — `inspiration.mp4`, тёмная тил/изумрудная сцена).
> `docs/brand/` (этот раздел) — **вышестоящий фирменный канон Сбера**. При конфликте фирменных
> вопросов (цвет бренда, шрифт, логотип, тон) канон — здесь; прикладные UI-паттерны портала
> остаются в `docs/design/`. Реконсиляция расхождений — ниже.

## Ядро фирменного стиля (одним экраном)

- **Палитра суббренда:** Королевский `#515DAD`, Голубой `#5AB0FF`, Аметист `#8253AA`,
  Аквамариновый `#6BEAC7`. Зелёный — только мастер-бренд Сбер.
- **Градиент:** аметист/королевский → голубой → белое ядро → аквамарин. На тёмном — яркие
  пятна на чёрном.
- **Шрифты:** SB Sans Display (заголовки), SB Sans Text (тело/интерфейс).
- **Графика:** Локатор (фирменный элемент), пиктограммы, пульсирующие градиент-иконки, паттерн-
  галочка.
- **Иллюстрации:** архетип «Маг» — условное пространство, градиенты без светотени.
- **Тон:** вдохновляющий, простой, активный залог, на «вы».

## Ассеты в репозитории

- **Шрифты SB Sans** — `docs/brand/assets/fonts/` (полный кит TTF/OTF/WEB) + `apps/web/public/brand/fonts/`
  (self-hosted woff2, `@font-face` в `apps/web/src/theme/brand.fonts.css`, токены `--font-brand-*`).
- **Логотип и локатор Sber AI** — `docs/brand/assets/logo/` (SVG/PNG/AI, RGB+CMYK) + `apps/web/public/brand/logo/`
  (веб-SVG). Использование — [logo.md](logo.md), [locator.md](locator.md).
- **Брендбук** — `docs/brand/assets/SberAI_guide.pdf`.

Всё доступно агентам в рабочем репозитории. SB Sans — глобальный шрифт портала (решение
оператора 2026-07-18 — [typography.md](typography.md)), токены `--font-brand-*` остаются
доступны и для точечного использования.

## 🔴 Реконсиляция с текущей дизайн-системой портала (решает оператор/CTO)

Портал развивал импровизированный визуал по `inspiration.mp4`; официальный гайд Sber AI даёт
канон. Точки расхождения, которые нужно решить **явно** (не молчаливой правкой — затрагивают
токены и весь UI):

| Вопрос | Портал сейчас | Официальный Sber AI | Статус |
|---|---|---|---|
| **Акцентный цвет** | мятно-зелёный `#34d399…#6ee7a7` (самостоятельный) | фиолетово-синий→аквамарин градиент; зелёный = мастер-бренд | ✅ решено: акцент остаётся мятным; градиент — только брендовые поверхности |
| **Дисплейный шрифт** | Unbounded | SB Sans Display | ✅ решено 2026-07-18: переключено на SB Sans |
| **UI-шрифт** | Inter / Golos Text | SB Sans Text | ✅ решено 2026-07-18: переключено на SB Sans |
| **Тёмная база** | тёмный тил `#0a1512` + мятный акцент | чёрный + яркие пятна палитры | ✅ совместимо (аквамарин ≈ наш мятный) |
| **Декор-элемент** | абстрактные blur-пятна `aurorabg` | Локатор + паттерн-галочка | ➕ добавить Локатор |
| **Скругления** | текущие радиусы | «квадрокруг» (гладкий squircle) | ✅ уточнить радиусы |
| **Иконки** | свой набор `ui/` | универсальный набор Figma + пульс-иконки | ➕ привести к канону |
| **Тон/копирайт** | «концизно, без воды» | вдохновение + простой активный залог | ✅ совместимо |

**Решения оператора (2026-07-16):**
- **Акцент — остаётся мятно-зелёным.** Токены `--accent*` не трогаем. Фирменный градиент Sber AI —
  справочник для брендовых поверхностей (логин/обложки/локатор/hero/паттерн/OG), не функциональный акцент.
- **Шрифт — решено (2026-07-18): переход на SB Sans.** `--ref-font-display`/`--ref-font-sans`
  (tokens.css) переключены на self-hosted SB Sans Display/Text — детали и покрытие в
  [typography.md](typography.md).

Итог: `docs/brand/` — **авторитетный фирменный справочник**; токены и UI портала массово НЕ
переписываются. Приведение к канону — точечно и по решению оператора, не по этому доку.

Прод-фиксация текущего решения бренда портала — [../product/brand.md](../product/brand.md).
