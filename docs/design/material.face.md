# `/materials/<id>` — детальная карточка материала

← [docs/design/readme.md](readme.md) · листинг и переход — [materials.catalog.md](materials.catalog.md) ·
карточка принтера как соседний паттерн — [printers.catalog.md](printers.catalog.md) · токены и
компоненты — [palette.typography.md](palette.typography.md), [components.md](components.md) · API —
[`apps/api/src/catalog/materials.ts`](../../apps/api/src/catalog/materials.ts).

**Что это.** Контракт detail для MF-1473: человек сверяет линейку материала, её реальные варианты
и уже опубликованные печати. Это не магазин, не профиль владельца и не мастер совместимости:
цена, остаток, покупка, «подходит моему принтеру» и редактирование здесь запрещены, потому что
`GET /materials/:id` их не отдаёт.

**Единый адрес.** Плитка ведёт на `/materials/<id>`, где `<id>` — UUID `material.id`. `slug` может
быть метаданным, но не заменяет адрес: API принимает только UUID. Кнопка «К материалам» возвращает
на `/materials` с сохранённым query string, а если его нет — на чистый каталог.

## 1. Данные и честные поля

| Блок | Разрешённые поля | Представление |
|---|---|---|
| Шапка | `vendor.name`, `name`, `material_type.name`, `kind` | eyebrow бренда; H1; «тип · класс» |
| Вариант | `color_name`, `color_hex`, `diameter_mm`, `weight_g`, `spool_type`, `sku` | текстовая строка в фиксированном порядке |
| Печати | `make_stats.make_count`, `make_stats.model_count`, `makes[].caption`, `printability_rating`, `created_at`, `model.title`, автор | счётчик и компактные текстовые карточки Make |
| Догрузка печатей | `makes_has_more`, query `limit`, `offset` | кнопка «Показать ещё» только при `true` |

`material.specs` и `variant.specs` — свободный JSON. Пока нет утверждённого словаря ключей,
неизвестные значения не становятся блоком «Характеристики». `color_hex` — только маленькая
декоративная точка рядом с обязательным именем цвета; невалидный или пустой hex скрыть. Цвет
никогда не является единственным носителем значения.

## 2. Desktop: иерархия без новой визуальной системы

Шапка каталога и тёмное стекло наследуются без нового языка. Контейнер центрирован в shell, но
текст внутри него имеет **левую выключку**: detail читается как рабочая карточка, а не промо-экран.
Сначала единая круглая `IconButton` «Назад к материалам», затем identity линейки. Ниже на desktop
— две содержательные колонки: варианты слева, примеры печати справа; до 900px они складываются
в одну ось. Нельзя создавать пустую боковую панель или выдуманный блок «О материале»: API не даёт
для них честного содержания. Нейтральный `MaterialMark` допустим только как тихая метка внутри
плитки каталога, а не как замена detail-контента.

```
┌──────────────────────────────────────────────────────────────────────┐
│ (←)                                                                    │
│ БРЕНД · КЛАСС                                                          │
│ Название линейки                                                       │
│ Тип материала                                                          │
├──────────────────────────────────────────────────────────────────────┤
│ ВАРИАНТЫ                              │ ПРИМЕРЫ ПЕЧАТИ · 12          │
│ ● Чёрный                 1,75 мм · 1 кг │ МОДЕЛЕЙ · 4                │
│   картонная катушка · SKU PLA-BLK      │ Make: подпись · модель      │
│ ● Белый                   1,75 мм       │ оценка · дата · автор       │
│ [Показать ещё]                         │ [Показать ещё]              │
└──────────────────────────────────────────────────────────────────────┘
```

Контейнер `wide` и интервалы — из `layout.md`; две колонки существуют только когда обе наполнены
честными данными. Заголовки секций — существующий `Eyebrow`; строки и
карточки используют `--surface`, `--border`, `--text`, `--text-dim`, радиусы и focus-стиль из
соседних каталогов. Один мятный акцент оставлен для keyboard focus и primary-кнопки догрузки.

## 3. Варианты

Секция `ВАРИАНТЫ` показывает первые шесть элементов `variants[]` в порядке API (`color_name`,
затем `diameter_mm`). Каждая строка — не кнопка, если у неё нет действия: она не создаёт ложный
выбор SKU. Имя цвета — у левого края, диаметр и вес — у правого; тип катушки и SKU становятся
вторичной правой строкой. Null-поля просто не рисуются; разделители появляются лишь между
существующими значениями.

Если вариантов больше шести, текстовая кнопка «Показать ещё» разворачивает остаток локально, без
повторного запроса. После раскрытия она меняется на «Свернуть варианты» и возвращает фокус к
заголовку списка; анимация только высоты/opacity 160–200ms и отключается для
`prefers-reduced-motion`. Если `variants=[]`, честная строка: «Варианты этого материала ещё не
добавлены» — без CTA на добавление.

## 4. Примеры печати

Заголовок строится из точных агрегатов: `ПРИМЕРЫ ПЕЧАТИ · {make_count}` и вторичная
мета `МОДЕЛЕЙ · {model_count}`. При `make_count=0` вместо пустого каркаса — «Печатей этим
материалом пока нет». Не обещать галерею: endpoint не возвращает изображений.

Карточка Make — текстовое стекло с `caption` (если есть), названием модели, оценкой печати и
датой/автором вторичным текстом. Отсутствующее поле скрывается, не заменяется прочерком. При
`makes_has_more=true` кнопка «Показать ещё» добавляет следующую страницу с тем же `limit`; старые
строки остаются на месте, кнопка получает `aria-busy` и «Загружаем…». При `false` кнопка и
финальная «вы посмотрели всё» не рисуются: API не сообщает total списка.

## 5. Mobile, доступность и состояния

До 900px сохраняется одна ось: шапка → варианты → примеры печати.
Строка варианта сохраняет имя слева и размер/вес справа; `IconButton` назад и любая реальная кнопка имеют
минимум 48×48px. Ссылки, кнопки догрузки и возврат доступны с клавиатуры, видимый focus не
перекрывается sticky-элементами; декоративная точка цвета имеет `aria-hidden`.

| Состояние | Поведение |
|---|---|
| Первичная загрузка | skeleton H1, шести строк вариантов и 2–3 Make-карточек; нельзя показать несуществующие действия |
| Догрузка Make | показанные данные остаются; busy только на нажатой кнопке |
| Ошибка сети/5xx | «Не удалось загрузить материал» + «Повторить» и ссылка «К материалам» |
| 401 | единый prompt входа с сохранением URL; не маскировать под 404 или пустой материал |
| 404 / не-UUID | «Такого материала у нас пока нет» + «К материалам» и переход к поиску |
| Пустые варианты | честная строка о том, что варианты ещё не добавлены |
| Пустые печати | «Печатей этим материалом пока нет» без фальшивых карточек |

## 6. Передача Front

- Переиспользовать `IconButton`, `EmptyState`, токены, focus-кольцо и `MaterialMark` из
  [materials.catalog.md](materials.catalog.md); не вводить отдельную палитру, шрифт или вид
  карточек.
- Обработать `200`, `401`, `404`, сеть/5xx, `variants=[]`, `makes=[]`, `makes_has_more` и
  невалидный `color_hex`.
- Протестировать desktop, tablet, mobile и `prefers-reduced-motion`; цветовая точка не должна быть
  единственным способом прочитать вариант.
