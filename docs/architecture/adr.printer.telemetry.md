# ADR: реальная телеметрия принтеров (протокол по бренду)

Статус: принято. Контекст: демо-мастерская использовала мок-телеметрию;
это крупнейший разрыв демо↔прод. Ниже — решение по протоколам на MVP.

| Бренд/прошивка | Протокол | В MVP? | Примечание |
|---|---|---|---|
| Klipper (Creality K1/K2, Voron, Sovol и т.п.) | Moonraker: HTTP + WebSocket JSON-RPC 2.0, свой лёгкий агент у принтера в LAN пользователя | Да | Де-факто стандарт open-source ферм, протокол открыт, объекты по подписке |
| Prusa (MK4/MK3.5/XL и т.п.) | PrusaLink локально: OpenAPI опубликован (github.com/prusa3d/Prusa-Link-Web `spec/openapi.yaml`), X-Api-Key | Да | Работает локально в сети пользователя, без облака |
| Bambu Lab (X1/P1/A1) | LAN/Developer Mode: MQTT :8883 (user bblp) БЕЗ извлечённого X.509-ключа | Да, только LAN-mode | Firmware янв-2025 требует X.509-подпись команд вне LAN-mode (ошибка 84033543). Путь с извлечённым из Bambu Connect ключом (Hackaday 2025-01-19) — юридически/стабильностно НЕДОПУСТИМ в коммерческом продукте (чужой приватный ключ, будет отозван). LAN-mode отключает Bambu Cloud — это принятый компромисс для MVP |
| Bambu Cloud / Prusa Connect (облачные API) | — | Отложено | Prusa Connect не публикует спеку (кроме camera API) — потребовал бы реверс-инжиниринга |
| Кросс-бренд-агрегаторы (SimplyPrint, 3DPrinterOS) | — | Отложено | Платные сторонние сервисы, добавляют внешнюю зависимость — рассмотреть после MVP если своя интеграция не покроет длинный хвост брендов |

Деградация без датчика остатка филамента: там, где принтер/спул не отдаёт
вес/длину остатка (нет физического датчика), оценка остатка филамента
считается по времени печати и профилю расхода материала (эстимейт, не
точное измерение) — помечать в UI как оценочное значение, не как точный факт.

Безопасность локального агента (отдельно от протокола): агент,
работающий в LAN пользователя и туннелирующийся к порталу, — новая
поверхность атаки и отдельный деплой-юнит (обновления агента, доступ к
локальной сети, аутентификация агент↔портал). Это кандидат в ОТДЕЛЬНЫЙ
эпик безопасности, не решается в рамках MVP-подключения телеметрии.
