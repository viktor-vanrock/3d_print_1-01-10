## Что новое

### Embed-реестр партнёрских доменов

Не generic Open Graph unfurl. Точечный реестр `домен → компонент` для
доменов, где заведён bespoke интерактивный блок (пример от оператора:
GigaChat, GitVerse, DomClick — список растёт по мере проработки новых). При
вставке ссылки: домен есть в реестре → рендерим специфичный интерактивный
блок вместо голой ссылки; домена нет — остаётся обычная ссылка.

Нужны два слоя:
- Серверный резолвер: парсит вставленный URL, матчит домен по реестру, тянет
  нужные данные под конкретный блок (для каждого домена — свой набор полей;
  GitVerse, например, естественно тянет PR/commit-метаданные через уже
  используемый `Accept: application/vnd.gitverse.object+json;version=latest`
  контракт, см. `docs/infra/readme.md` § «GitVerse Public API»).
- Фронтовый реестр компонентов рендера — по домену выбирается конкретный
  React-компонент блока.

### Темы/подписки UX

Экран выбора тем (при регистрации и/или в профиле), лента получает режим
«по подпискам» в дополнение к текущему ранжированию/хронологии.

## Масштаб

Embed-реестр — новая подсистема (резолвер + фронт-реестр + минимум пара
готовых блоков для запуска), это делает эпик заметно больше, чем «дизайн
редактора». Не фазирую заранее — при старте работы декомпозировать на
Ф1 (embed-реестр backend + 1-2 готовых блока) / Ф2 (темы/подписки UX) /
Ф3 (полировка + 3D-embed доводка), по обычному паттерну доски.
