# connector/flsun — FLSun (позже)

Парк оператора с FLSun (T1 Max, V400 и др.) сейчас **недоступен** — коннектор пишется,
когда оператор откроет парк. До железа допустимы только работы против доков/эмуляторов.

Ожидания (проверить на железе, НЕ факт): FLSun ходит на Klipper — вероятен живой
Moonraker (порт 7125). Тогда коннектор здесь тонкий: discovery + доступ, протоколом
работает готовый `driver/moonraker/MoonrakerDriver` (пилот FLSun V400 уже в планах
эпика MF-879).

Реализует `../common/connector.ts`; auth с участием оператора — через
`OperatorConfirmGate` (см. `../common/README.md`).
