# Шов `db-rows` — кросс-доменное ЧТЕНИЕ строк БД

Типы строк таблиц для читателей из ДРУГИХ доменов. Правило: **писать в таблицу может только её
владелец-домен** (§2 карты); остальные читают типизированно отсюда, но НЕ пишут. Схема/миграции —
**Data** (dbmate, `apps/api/db/migrations`), это единственный владелец DDL.

Наполнять по мере появления кросс-доменного чтения (напр. `feed` читает `users`/`models`,
`compat` читает `machines`/`materials`). Своя таблица типизируется в своём домене, не здесь.
