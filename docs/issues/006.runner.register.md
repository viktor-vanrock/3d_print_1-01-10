# 006 · Зарегистрировать self-hosted раннер деплоя

**Статус:** open
**Тип:** infra
**Создано:** 2026-07-03

## Суть

Деплой-джобы (`.gitverse/workflows/release.yaml`/`deploy.yaml`) должны выполняться на VDS через self-hosted GitVerse Actions runner (метка `deploy`). На VDS готовы `~/gitverse.runner/` + systemd-юнит `gitverse.runner.service`. Апстрим-бинарь `act_runner` с `dl.gitea.com` **проверен и несовместим** (протокол GitVerse форкнут, `error=unimplemented`) — нужен бинарь именно с панели.

## Что сделать

1. `gitverse.ru/plag/portal.ru` → Settings → Actions → Runners → Add Runner → скачать бинарь под linux/amd64.
2. Передать бинарь на VDS в `~/gitverse.runner/act_runner` (я могу забрать и доустановить сам после этого).

Токен регистрации получать не обязательно руками — есть рабочий API-путь (`docs/infra/readme.md` § «GitVerse Public API», `POST .../actions/runners/registration-token`), это я могу сделать сам.
