## Идеи из демо-прототипа (`3dmake/DEMO.md`, мок-визия, НЕ спека — источник вдохновения)
Демо (`draft.plag.space/3dmake/demo`) — идеалистичный прототип «управления мастерской», отдельный от нашего кода стек. Полезные продуктовые идеи оттуда, ещё не приоритизированные:
- **Режимы Lite (дом, 5–15 принтеров) ⇄ Pro (ферма, 100–200)** — не просто разные персоны, а явный тумблер темы+дашборда. Хорошо ложится на наш разброс персон (новичок ↔ принт-ферма).
- **Управление парком принтеров** — статус/телеметрия (темп/сеть/калибровка), обслуживание по наработке узлов, история печати. Ни у MakerWorld, ни у Printables этого нет — они чистые маркетплейсы, не device-менеджмент. Потенциальный дифференциатор поверх «мультипринтер».
- **Контроль филамента на масштабе фермы** — остаток на катушке vs нужно для текущего задания, алерт «на полке A16, заменить через 24 мин», дозаказ по низким остаткам. Естественно тянется к нашим RU-партнёрам по филаменту (docs/product/market.md).
- **AI-ассистент на странице принтера** — контекстные советы по материалу/настройкам Klipper. Конкретизация уже заявленной «AI-диагностики по фото».
- **Гостевой QR-запуск** — сторонний человек сканирует QR и просит запустить печать на чужом принтере. Вариант print-on-demand полегче полноценного агрегатора мастеров.

## Модель монетизации (кандидаты)
- Take-rate с продажи цифровых моделей.
- Take-rate/подписка с Make-заказов (печать на заказ у мастеров).
- SaaS-подписка для мастеров/принт-ферм.
- Корп-подписки для B2B-заказчиков.
- Эквайринг-спред.

Скоуп версий зафиксирован в [roadmap.md](roadmap.md); каталог фич и модель монетизации — кандидаты, приоритизируются по мере продуктовых решений (не блокируют v1).
