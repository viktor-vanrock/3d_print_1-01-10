# MF-1294: gate приёмки первой волны

Этот gate относится к карточке **MF-1345** и не заменяет проверку самой
credential. Его задача — не допустить закрытия кодовой карточки по одному
комментарию, marker-коммиту или локальному тесту.

## Чек-лист

- [ ] MF-1294-A, B, C и D имеют воспроизводимые шаги, результат и commit с
  собственным ключом (`MF-1294-A` … `MF-1294-D`), если менялся код.
- [ ] MF-1294-E имеет живое подтверждение на dev: `relay.dev.3mf.tech/health`
  доступен, неверная/отозванная credential отвергнута, валидная ротация
  восстанавливает авторизацию, устройство сохраняется.
- [ ] В evidence нет секретов, токенов, enroll-кодов или сертификатов; логи не
  содержат credential и не раскрывают её значение.
- [ ] Явно отмечено, что production, печать, upload, прошивка и физический
  reset не выполнялись.
- [ ] Commit текущей карточки содержит `MF-1345`, рабочая копия чистая, commit
  является предком `origin/dev`.
- [ ] Для каждого затронутого web/api/device-agent/relay-контура marker в
  `/home/plag/.local/state/portal-deploy-dev/<surface>.sha` равен commit SHA.
  Для docs/scripts-only изменения marker не требуется.
- [ ] Публичный dev smoke выполнен после доставки: URL, API health, сценарий
  отказа и recovery подтверждены; production URL в проверке не используется.

Проверка Git/evidence выполняется без доступа к production или устройствам:

```bash
scripts/mf-1294-acceptance-gate.sh \
  --commit HEAD \
  --evidence ./mf-1294-evidence.md
```

Ненулевой код означает `BLOCKED`; такую карточку нельзя переводить в `done`.
Для MF-1345 скрипт намеренно требует `--evidence`: локальная сборка или marker без
подтверждения recovery недостаточны.

## Вердикт первой волны на 13.07.2026

Приёмка заблокирована. Единственное доступное живое подтверждение сообщает,
что `relay.dev.3mf.tech/health` вернул HTTP 400 вместо обязательного 200; без
здорового relay и защищённого тестового набора нельзя честно подтвердить
отозванную credential и recovery после ротации. Локальные тесты device-agent
не заменяют это доказательство. До устранения блокера кодовые карточки MF-1294
не закрываются.
